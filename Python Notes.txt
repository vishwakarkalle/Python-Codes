#Deep copy & shallow copy methods in Python:-
===========================================
1) Shallow copy methods:-
In the shallow copy method it can copy/add the any elements to its oringal list but the values which are present inside the list are not changed or affected it remains the same, it only adds the inside the list values.
original=[53,24,12,87[91,09,18],100,03]

Here we use the deep copy in the nested Mutable list/objects to add any element then this deep copy method add the given values to the deep copy list not to the original list, here the original copy lists remains the same.

When to use Shallow Copy and Deep copy:-
======================================
 Scenerio                                            Use
 1) Flat(simple) list/ dictionary(no nesting)      1) Use shallow copy(faster)
 2) Nested data u wil modify                       2) Deep copy(safe)/(slower)
 3) Only modifying the outer level                 3) Shallow copy

Catching Multiple Exceptions in One block:-
If you want to handle several exception types the same way, group them in a tuple.

here u can combine ValueError & ZeroDivisionError into single block and written is as "except block" which will print as "Invalid input"
example.py:-
try:
   num=int(input("Enter a number: "))
   result= 100/ num
except (ValueError, ZeroDivisionError):
   print("Invalid input. try again.")

Both ValueError and ZeroDivisionError are caught by this single except block.
Use this when the response is the same for different errors.
Use separate except blocks when each error needs its own handling.

Try-except-else-finally together:-
--------------------------------

==========
          try:

            print("You can't divide by zero.')
         else:
            print(f"Result: {result}")
         finally:
              print("Calculation attempt complete.")

'+'             Read + write       Combined mode(eg:- 'r+','w+')

we can also combine 'rb' - read binary, 'w+' = write and read.

Binary vs Text Mode:-
===================
File come into two flavors:-
Text mode 't'(Default)- for human-readable files: .txt,.csv,.py,.json
Binary Mode 'b' - for non-text files: images,PDF's,videos,excutables.

key difference:-
=============
Text mode --> reads/writes --> strings
Binary mode --> reads/write --> bytes

Tip:- if your are working with anything other than plain text - images,audio,PDF's - u need binary mode.

How Python Finds Modukes:-
=========================
When u write a import calculator, where does Python actually work?
Python searches these location in order:
1) The current directory(where our script runs)
2) Directories in the PYTHONPATH env variable.
3) The standard library directories.
4) The site-packages folder(where pip installs third-party packages)
You can see the full search path:

import sys
print(sys.path)       #list of directories python searches.

WatchOut:- If Python can't find ur module, we will get a "ModuleNotFoundError". Usually it means the file isn't in any othese searches locations.

Concurrency (vs) Parallelism:-
============================
Two words that sound similar but mean different things:-

Concurrency:- Managing multiple tasks at once by switching b/w them Quickly.They may not run at at the exact same instant - they take turns.
ex:- One chef juggling b/w 3 dishes,switching b/w them.

Parallelism:- actually running multiple tasks at the same instant, on multiple CPU Cores.
ex:- Three chefs, each of them cooing one dish simultaneously.

Quick Tip:- Concurrency is about structure. whereas Parallelism is about execution.


Process (vs) Thread:-
==================
The Two fundamental unit of execution.

1.Process:- An independent program with its own memory space.
Heavyweight - more overhead to create.
Processess dont share memory by Default.
Ex:- Opening two separate instances of an app.
Google app --> open chrome ---> hence its a process running.
App -> VLC --> Process 
App -> Paint --> Process

2.Thread:- A lightweighted unit that lives inside a process.
Multiple threads shares the same memory of their process.
Cheaper and faster to create.
Ex:- A single app handling UI + downloads at once.

One process can contain many threads. Threads share memory- convenient but risky. Processess are isolated.

Process "A"                              Process "B"
shared Memory(code,Data,Heap etc)        Isolated Memory
  |    |       |                              ||
(Thread 1)   (Thread 2)  (Thread 3)         (Thread 1)

Threads share. Processess are isolated.
